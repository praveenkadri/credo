# Nivo / Wealthsimple Reference

This file is reference-only. It does not override `AI/design-system/credo-design-system.md`.

## Shared visual direction

Nivo and Credo should feel top 1%, not like regular SaaS dashboards.

Shared traits:
- warm neutral shell
- layered surfaces
- calm typography
- soft financial confidence
- less UI, more hierarchy
- simple human language
- high trust, low noise

## Nivo reference tokens

Nivo inspiration:
- Shell: `#F2F1ED`
- Panel: `#FFFFFF`
- Tinted surface: `#F8F7F4`
- Ink: `#151713`
- Muted text: `#74776F`
- Accent green: `#0B5A3D`
- Accent pale: `#EDF5EF`
- Warning: `#E88916`
- Danger: `#C9332A`

Credo may use the same green family, but it must feel more operational and business-focused.

## Wealthsimple behavior to copy

- Keep main workspace calm.
- Do not explain the app in the main body.
- Keep next actions contextual.
- Use whitespace as structure.
- Reduce chrome.
- Prefer one clear next step.
- Hide what is not currently useful.

## Wealthsimple behavior not to copy literally

- Do not force an icon-only sidebar if Credo’s compact labeled sidebar is working.
- Do not use consumer finance copy for payroll/business operations.
- Do not add net-worth-style charts unless the Credo data truly supports it.
