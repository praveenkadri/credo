# Overview and Empty-State Rules

The Overview page is the calmest page in Credo.

It should not become an onboarding dashboard.

## Overview target structure

```txt
Setup banner, if needed

Cash movement
$0.00
No payroll activity yet

Companies
Company row/list

Right rail
One next step
```

## Main body hard rules

No instructional help text in the main dashboard body.

Remove paragraphs like:
- “This workspace is set up, but…”
- “Cash movement will stay quiet until…”
- “Next steps live in the rail…”
- “Start by…”
- “Once you…”

The main content is for product surfaces, not onboarding documentation.

## Empty state format

Use one clean section:

```txt
Eyebrow
Large value or title
One short empty label
```

Example:

```txt
Cash movement
$0.00
No payroll activity yet
```

## Do not add

- setup status grids
- readiness rows
- multiple inner cards
- duplicated action clusters
- fake preview modules
- repeated empty illustrations
- large instructional cards
- placeholder dashboards

## Whitespace rule

Whitespace is better than fake density.

If the page feels empty, first check whether the hidden module should stay hidden until useful.

## Companies section

Keep company rows calm and row-like.

Do not add a large company setup dashboard in the overview.

If there are no companies, use the right rail primary action: “Add company”.
