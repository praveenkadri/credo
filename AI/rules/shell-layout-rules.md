# Shell and Layout Rules

Credo’s shell should feel compact, quiet, and WS/Nivo-like.

## Preserve

- compact sidebar
- warm neutral canvas
- calm topbar
- soft right rail
- deep green active nav
- low-border surfaces
- tight sidebar-to-main spacing
- tight main-to-right-rail spacing

## Avoid

- large gaps between shell regions
- dense admin navigation
- full-width green backgrounds inside the app
- heavy borders
- oversized empty cards
- stacked dashboard widgets

## Sidebar

The sidebar is progressive. It should not expose modules before they are useful.

Active nav:
- soft green wash
- green icon/text
- rounded pill
- low border

Inactive nav:
- muted but readable
- no noisy badges
- no disabled future modules

## Topbar

Topbar should remain calm and not compete with the page.

Use topbar for:
- company selector
- search
- date/context
- notifications
- workspace identity

Do not use topbar for large instructional banners.

## Right rail

Right rail should feel like a floating, soft support surface.

It should be present only when useful.

Do not force a right rail onto simple list pages unless there is a real functional need.
