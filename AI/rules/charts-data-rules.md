# Charts and Data Rules

Charts should appear only when data exists or when they are the true center of the page.

Credo should not use fake chart previews to fill space.

## Chart rules

- Use thin, precise strokes.
- Use green for trusted positive financial movement.
- Use muted ink/grey for neutral context.
- Use tabular numbers for axis and values.
- Avoid loud gradients.
- Avoid generic analytics widgets.

## Data rows

Rows should be calm and ledger-like.

Prefer:
- row hierarchy
- soft separators
- hover-revealed actions when appropriate
- aligned numbers

Avoid:
- boxed rows inside boxed cards inside boxed pages
- too many badges
- overcolored status labels
