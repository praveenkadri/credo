# Design Review Checklist

Run this before finishing any UI task.

## WS/Nivo calm

- [ ] Does the screen feel calm and premium?
- [ ] Does it avoid generic SaaS dashboard patterns?
- [ ] Are there fewer surfaces than before?
- [ ] Is whitespace used intentionally?
- [ ] Is there one obvious next action?

## Progressive disclosure

- [ ] Are irrelevant modules hidden from the sidebar?
- [ ] Are empty pages avoided instead of decorated?
- [ ] Are hidden routes still safe when manually visited?

## Main content

- [ ] No long instructional paragraphs in main content.
- [ ] No setup grids on Overview.
- [ ] No readiness rows on Overview.
- [ ] No fake preview modules.
- [ ] Main content shows real data, rows, metrics, or minimal empty state.

## Right rail

- [ ] Right rail has one primary next step where possible.
- [ ] No stack of equal CTA buttons.
- [ ] No duplicated actions from main content.
- [ ] Filter rails are not heavier than empty main pages.

## Visual system

- [ ] Credo green leads the identity.
- [ ] Green is not overused.
- [ ] Buttons use tokenized colors.
- [ ] Active nav uses soft green.
- [ ] Borders are soft and rare.
- [ ] Shadows are atmospheric, not decorative.

## Typography

- [ ] Plus Jakarta Sans is used.
- [ ] Money values use tabular numbers.
- [ ] Micro labels are uppercase and letter-spaced.
- [ ] Copy is simple and human.

## Component discipline

- [ ] Repeated patterns use reusable components.
- [ ] No new one-off styling for repeated elements.
- [ ] No parallel design system was invented.
